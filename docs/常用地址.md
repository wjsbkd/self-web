# 常用地址

> 建立：2026-10-27 · 本项目所有对外地址、控制台入口与本地调试端口的一页清单。
> 用途：换设备、交接、或隔几个月回来时，不用翻 HANDOVER 全文找网址。
> 核验方式见文末「本文的核验状态」——**带 ✅ 的是实测过的**。

## 一、核心（建议常驻书签）

| 地址 | 是什么 |
|---|---|
| https://wjsbkd.github.io/ | **作品集主站（前台）**。对外展示的唯一入口，所有内容从这里加载 |
| https://wjsbkd.github.io/admin/ | **内容管理后台**（Sanity Studio，已中文化）。作品、分类、简历、站点设置都在这里改；先点页面里的登录按钮。改完点「发布」才会出现在主站 |
| https://github.com/wjsbkd/self-web | **源码仓库**（公开，默认分支 `master`）。改代码推这里 |
| https://www.sanity.io/manage/project/ncixtjar | **Sanity 项目控制台**。成员、API 用量、套餐、数据集可见性、API tokens 都在这里。**界面只有英文**——那是 Sanity 自己的产品后台，不是本项目的前后台，无法中文化 |

`/admin`、`/admin/`、`/admin.html` 三种写法都能打开，收藏任一即可
（构建插件 `emit-admin-index` 会把 `dist/admin.html` 复制成 `dist/admin/index.html`，见 `vite.config.ts`）。

## 二、部署与发布

| 地址 | 是什么 |
|---|---|
| https://github.com/wjsbkd/self-web/actions | 部署工作流「**部署站点**」。push 到 `master` 触发，一次构建同时发布 GitHub Pages（主站）+ Cloudflare Pages（备用），约 1 分 20 秒。**注意带 `paths` 白名单**：只有 `src/**`、`public/**`、`index.html`、`admin.html`、`sanity.config.ts`、`package.json`、`package-lock.json`、`vite.config.js`、`wrangler.toml` 改了才构建——只改 `docs/**` 或 `HANDOVER.md` 时**不会**有新运行，这是正常的，不是部署失败 |
| https://github.com/wjsbkd/self-web/actions/workflows/smoke-test.yml | 「**线上冒烟测试**」，手动触发（`workflow_dispatch`，无定时）。验证四件事：主站与 `/admin` 返回 200 且引用预期 bundle 哈希、`robots.txt` 屏蔽后台、Sanity 数据 API 带 `Origin` 头返回 CORS + 真实数据、Sanity CDN 图片返回 `image/webp`。怀疑「后台改了内容前台没变」时跑一次 |
| https://lizongheng-portfolio.pages.dev/ | **Cloudflare Pages 备用站**，内容与主站完全相同 |
| https://github.com/wjsbkd/wjsbkd.github.io | GitHub Pages 的**站点仓库**：部署流程把 `dist/` 强制推到这里才上线。日常不用手动打开 |

**哪个更快就用哪个**：2026-10-26 做过 8 轮中位数实测，同机同网络下 GitHub Pages（节点在首尔 ICN）明显快于 Cloudflare（Anycast 落点西雅图 SEA）——JS p50 0.77s vs 4.70s，`main.mp4` 3.6–4.9s vs 38.3–57.9s。
因此**日常一律用主站**，不要主动切到 Cloudflare；后者只是 GitHub Pages 故障时的兜底。域名元数据也已全量回退到 `wjsbkd.github.io`。

## 三、只有调试时才用

| 地址 | 是什么 |
|---|---|
| https://www.sanity.io/manage/project/ncixtjar/datasets/production | 直接查看数据集里有哪些文档、哪些是 `drafts.` |
| https://ncixtjar.api.sanity.io/v2021-10-21/data/query/production | 数据 API 端点。**不带 `?query=` 直接打开会返回 400，这是正常的**（缺参数），不是链接坏了；带上 GROQ 查询才有数据，主要用来确认发布/草稿状态 |
| https://cdn.sanity.io/images/ncixtjar/production/… | 图片 CDN。前台图片都从这里取，可加 `?w=800&fm=webp&q=82` 等参数 |
| http://localhost:5173 | 本地前台开发（`npm run dev`） |
| http://localhost:4173 | 本地预览构建产物（`npm run preview`），最接近线上 |
| http://localhost:3333 | 本地启动后台 Studio（`npm run studio`），调 schema / 界面时用 |

前三个本地端口写在 `.claude/launch.json` 里（`site` / `site-built` / `studio`）。

## 四、配置事实（不用去代码里翻）

| 项 | 值 |
|---|---|
| Sanity projectId | `ncixtjar`（**不是机密**，会出现在前台 CDN 请求域名里） |
| dataset | `production` |
| apiVersion | `2021-10-21` |
| 数据集可见性 | 公开（public）——前台匿名只读，靠 CORS 放行域名 |
| 写入方式 | Studio 登录会话，**项目里不存在任何写 token** |
| `.env.local` 键名 | `VITE_SANITY_PROJECT_ID` / `VITE_SANITY_DATASET` / `VITE_SANITY_API_VERSION` / `SANITY_STUDIO_PROJECT_ID` / `SANITY_STUDIO_DATASET`（全是配置名，无密钥） |
| 套餐 | Sanity **Free 计划，永久 $0**。用量（12 篇文档 / 1 成员 / 1 数据集）比 Free 上限低两个数量级；即使 Growth 试用到期也会**自动降级到 Free，不扣费**，主站不受影响 |

### 草稿为什么不会漏到正式站

对公开数据集的匿名请求，Sanity 只会返回 `_id` 中不含点号的文档——这天然排除了全部 `drafts.` 与 `versions..`。
再加上 `src/sanity/client.ts` 显式写了 `perspective: 'published'` 且 `useCdn: true`，是双保险。
2026-10-27 匿名实测：`count(*[_id in path("drafts.**")])` = 0。
